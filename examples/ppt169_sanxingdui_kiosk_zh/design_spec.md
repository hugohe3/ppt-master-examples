## III. Visual Theme

### Theme Style

- **Mode**: custom
- **Mode References**: instructional
- **Mode Behavior**: 以 instructional 的「拆解后排序」为唯一骨架，改造成触摸屏的菜单式讲解：首页把全卷拆成四个可点入口并给出每条路径的长度预期；每个展区先用章节页交代「这一段要看什么」，再用内容页逐步展开；重点文物区把七件器物做成完全平行的展开——每页固定「年代 / 坑号 / 关键尺寸 / 看点」四件事，同序同深度，让观众能横向比较；页标题写这一页教什么，不写判断句。观众可以从任意入口进入、任意时刻退出，因此每页自足，不依赖上一页的铺垫。
- **Visual style**: custom
- **Visual Style References**: dark-tech
- **Visual Style Behavior**: 取 dark-tech 的暗场—发光—几何精准三件事，换成青铜与黄金的语汇：近黑墨绿满铺作深度，细金线与低透明度巨大编号浮在内容层之后，卡片用 1px 金色描边而非填充块，边角近直角（8px）；注意力靠局部高对比的金色发光承担，其余一律压低；纵深靠外发光与层叠，不用投影；文物照片以暗场直接承托、加极轻的暗角压边，不套框。等宽体只用于尺寸与坑号这类需要精确读数的标签，正文保持中文黑体的清晰度。
- **Theme**: 深场金光——观众在偏暗的展厅里抬眼看屏，屏幕本身是一盏灯；金色只出现在「可点」和「关键数字」两处，从而让导航与事实自己发光
- **Tone**: 庄重、可靠、克制；博物馆标牌的语气，不是营销页的语气

## V. Layout Principles

### Deck-wide Direction

- **Hierarchy direction**: 视线先落在页面上三分之一的标题或主图，再向下走到事实块，最后才到底部导航条；导航条位置全卷恒定，观众一旦学会就不必再找
- **Composition tendency**: 内容页偏向「左事实 / 右图像」或「上主视觉 / 下四栏事实」的双区关系；菜单页与目录页用可点条目的纵向排布承担全部构图；文物页固定同一宏观关系，靠内容差异而非构图差异产生变化
- **Cross-page continuity**: 底部导航条、页码、来源行三件框架元素全卷同位同形；每个展区有一个恒定的色标（accent 色块 + 展区名）留在页眉；文物页的四栏事实块在七页之间保持同一相对关系，只有内容与主图变化
- **Spacing posture**: variable by page rhythm——章节页与菜单页留白充分，文物页与速查表偏紧凑但受栅格约束
- **Spacing anchors**: page margin 64 px；block gap 28 px；column gutter 32 px；corner radius 8 px；body leading 1.55

#### Slide 03 - 百年发现时间线（整理）

- **Audience move**: 以为三星堆是 2021 年才被发现的 → 知道它从 1929 年起被反复发现，1986 年是转折
- **Relationships**: 四个时间节点（1929 / 1934 / 1986 / 2019–2022）之间为 order 关系；每个节点与其出土数量之间为 link 关系
- **Composition**: 一条横贯页宽的时间轴，四个节点等距落在轴上，每个节点下方是一组「年份 + 一句话 + 数量」
- **Title**: 百年发现：从一条水沟到八座祭祀坑
- **Core message**: 三星堆的发现是一条近百年的链条，1986 年那两座坑才让它进入公众视野
- **Content**:
  - 1929：燕道诚父子在广汉南兴镇挖沟时发现 300 多件玉石器
  - 1934：华西大学博物馆馆长葛维汉组织考古队发掘 10 天，出土陶器石器玉器等 600 多件
  - 1986.7.18：砖瓦厂工人取土挖出器物，一号祭祀坑显露，出土铜器金器玉器等珍贵器物 420 件、象牙 13 根
  - 1986.8：二号祭祀坑随即现世，青铜大立人、青铜神树出自其中；两坑发掘由四川省文物考古研究院陈德安、陈显丹主持
  - 2019.11–2020.5：新发现 6 座「祭祀坑」，编号 K3–K8
  - 页面标注：本时间线为导览整理，节点取自各条来源的原始表述
- **Hyperlinks**: 底部「回首页」→ 同卷第 1 页；「上一页」→ 同卷第 2 页；「下一页」→ 同卷第 4 页
- **Motion suggestion**: 时间轴先画出，四个节点按年份顺序依次点亮，每个节点的说明文字在该节点出现之后才进场；章节标识由第 2 页延续而来
- **Fact IDs**: F014, F015, F016, F017, F018, F020, F028
- **page_rhythm**: dense

#### Slide 04 - 八座祭祀坑与它们的年代

- **Audience move**: 不清楚「坑号」是什么意思 → 知道一共八座、分两批发现，并知道碳十四给出的确切年代区间
- **Relationships**: K1–K2 与 K3–K8 之间为 contrast 关系（两批发现，相隔三十余年）；八座坑与祭祀区之间为 membership 关系；出土总量的两种口径之间为 contrast 关系
- **Composition**: 上半为八个坑号的方阵，前两个与后六个用色标区分；下半为一条年代结论与两行口径说明
- **Title**: 八座祭祀坑：两批发现，一个年代
- **Core message**: 八座坑分两批被发现，碳十四把它们的埋藏年代收进公元前 1131 年至前 1012 年
- **Content**:
