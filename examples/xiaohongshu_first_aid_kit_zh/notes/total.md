# 01_cover

我们今天讲一件几乎每个家庭都会踩的坑:家里的药箱不等于急救包。很多人家里药盒堆了一抽屉,可是真的切到手、烫到胳膊的时候,翻半天找不到一块纱布、一瓶碘伏,整个人就卡在那儿。这一组九张图,就是把家用急救包应该配什么、哪些东西必须清出去、放在家里哪个位置、多久检查一次,以及割伤和烫伤这两种最常见的意外该怎么处理,一次讲完。页面上标注的依据,主要是应急管理部二〇二〇年发布的全国基础版家庭应急物资储备建议清单、北京急救中心同年发布的家庭医疗应急物品指导目录,以及国家药监局和卫健系统的公开科普。

---

# 02_four_categories

先给大家一个记得住的骨架。急救包齐不齐,不要数件数,要看四个类别是不是都在:止血包扎、消毒、常用药、工具。止血包扎解决的是先止住、先盖住;消毒解决的是清洁创面、降低感染;常用药是对症备用,不是囤货;工具这一类最容易被忽略,但它决定了你到底能不能动手,也决定了施救的人自己有没有防护。这里要说清楚一点:把物品分成这四类,是我们为了好记做的整理。官方的两份目录里,应急管理部那一份是家庭应急口径,里面还包括灭火器、救生哨这类东西;北京急救中心那一份才是医疗急救口径,做家用急救包更贴题。

---

# 03_bandage_antiseptic

先看前两类。止血包扎里,无菌纱布建议三乘三英寸和四乘四英寸各备五片,弹力绷带三英寸和四英寸各一卷,三角巾两条,医用胶带一卷,再加上多种尺寸的创可贴大约二十五片。这个数量是美国红十字会针对四口之家给出的最小配置,家里人多就按比例往上加。消毒这一类,国内官方科普的首选组合是医用碘伏加无菌棉签,理由是碘伏对皮肤黏膜没有刺激也没有腐蚀,可以直接用在伤口上,还能在创面形成保护膜。生理盐水值得单独备一份,百分之零点九的生理盐水冲洗伤口是最好的处理方法。消毒湿巾只用来擦伤口周围的皮肤,不要直接盖在创面上。有一个禁忌一定要提醒:碘过敏的人禁用碘伏,甲亢病人要慎用。

# 04_medicine_tools

第三类是常用药。官方科普把它按用途分成五类:退烧止痛、抗过敏、肠胃应急、外用止痛、清凉解暑,原则是对症备用,不盲目囤货。在这个基础上按家里人追加:确诊冠心病的老人常备硝酸甘油片或者速效救心丸,再配一台上臂式电子血压计;有小孩的家庭补儿童退热药、退热贴、无菌敷贴、蚊虫叮咬膏和生理盐水洗鼻剂。另外别忘了把家人长期服用的药和写好的紧急联系电话也放进去。第四类是工具,一次性医用外科手套、医用外科口罩、护目镜、医用圆头剪刀、镊子、非水银非玻璃的电子体温计,再加上急救毯、带单向阀的人工呼吸面膜,还有一支建议放在床头的手电筒。电子血压计要记得定期检查电量和校准。这一页只给品类,不给任何剂量,具体用药请遵医嘱或者看说明书。

# 05_clear_out

接下来是很多家庭最需要做的一件事:把不该留的清出去。第一样是红药水,也叫红汞或者汞溴红,它的穿透力很弱、抑菌作用小、消毒效果并不可靠,而且含有汞的有机化合物,对人体有毒,大面积皮肤擦伤的时候使用可能造成大块皮肤坏死。第二样是紫药水,也就是龙胆紫,它收敛结痂快,不适合较深或者较脏的伤口,痂下容易积存脓液,而且近年来被发现是潜在的致癌剂。药监部门的明确建议就是,最好不要用红汞和龙胆紫涂擦伤口,红汞还不能和碘酊混用。第三样是酒精和碘酒直接涂在伤口上,这两样只能用于伤口周围皮肤消毒,直接涂在创面上会刺激疼痛、让创面蛋白凝固、影响愈合,碘酊涂完还需要用百分之七十五的酒精脱碘。第四样是过期药和已经变质的药,药效全无不说,还可能引发不良反应;药品变色、粘连、变硬变软、开裂缺角,即使没到有效期也不要再用。清出来的药不要直接扔,按国内口径,先破坏药品包装盒,再随生活垃圾分散丢弃,或者送到正规回收点集中做无害化处理。最后提一个存在争议的条目:止血粉,应急管理部的清单把它列入外用药品,但国防部网刊发的止血包扎科普明确说处理伤口时尽量不要用,理由是刺激伤口、盖住创面、影响医生诊断和二次处理,所以我们这份清单不把它列为必备。

# 06_where_and_when

配齐之后是两件很容易被忘掉的事:放哪儿,多久查一次。放的环境要阴凉、干燥、通风、避光,远离炉灶、水槽和发热电器,抽屉、橱柜、储物盒、壁橱都可以。特别要强调的是别放卫生间,淋浴和洗手台带来的高温和潮气会让药品在有效期之前就变质。位置还要同时满足两个条件:孩子看不见也够不着,最好放在带儿童安全锁扣的柜子里,同时家里的成年人都熟悉、一伸手就能拿到。车上可以另外放一个急救包,但是药品不要放在汽车手套箱,那里可能过热、过冷或者受潮。检查周期,国内卫健系统的建议是每三个月自查一次,查有效期、查工具是否完好、补齐缺失的、换掉过期或破损的;美国红十字会的口径是每年做一次完整复核,我们把它作为一年一次彻底翻箱的补充节点。一次检查可以按五步走:先看箱体能不能正常开合、有没有破损锈蚀,再逐件取出检查包装有没有破损污渍渗漏、是否过期,然后清理箱内灰尘碎屑,更换过期或损坏的物品,最后记下这次检查的时间,把记录留在箱子旁边。物资的保质期也给大家一个参考:胶带、敷料、纱布绷带、无菌纱布、冰袋、手套、剪刀、镊子在包装完好的情况下可以放到五年,酒精湿巾和抗生素软膏大约两年。创可贴和胶布即使没变质,黏性也会随时间下降,纱布包装受潮或者变色,即使没过期也应该更换。

# 07_cut_bleeding

现在进入第一条现场流程:割伤出血。先做一个判断,伤口深不深,出血止不止得住。如果是浅表的小伤口,自己就能处理:先洗手避免感染,用流动清水冲洗伤口降低感染风险,用肥皂清洗伤口周围但不要让肥皂进入伤口;然后用碘伏清洗伤口本身,伤口周围可以用酒精或碘酒,消毒的方向是从伤口内向外,不要拿擦过周围皮肤的棉球再去擦伤口;最后薄薄涂一层抗生素软膏或者凡士林保持创面湿润,再用创可贴或纱布盖上。注意,浅表伤口不要让它自然风干,愈合需要湿润环境,包扎也不要过紧,过紧会阻碍血液循环、让愈合变慢。如果伤口很深、出血不止,或者你不确定严重程度,顺序就反过来:先拨打一二〇,有条件的话先戴上一次性手套做防护;明显的表面异物可以清除,但是大的或者深深嵌入的异物不要拔出来,也不要去探查伤口;然后用无菌纱布或者干净的布覆盖伤口,用手掌用力按压直到出血停止,可能的话把伤处抬高到心脏水平以上;最后遵循先盖后包、力度适中的原则加压包扎,过松止不住血,过紧可能造成远端组织缺血坏死。有几条硬规则一定要记住:血渗透以后在原来的敷料上再加纱布继续按压,不要把原敷料揭下来;不要按压眼部损伤处和嵌入异物处,怀疑颅骨骨折的时候不要按压头部伤口;止血带只在有成品止血带并且受过训练的情况下使用,不要用围巾、皮带临时自制。最后是四种必须立即拨打一二〇的情况:持续胸痛超过十五分钟,意识模糊或者抽搐昏迷,严重创伤或者出血不止,呼吸困难面色青紫。

# 08_burn_five_steps

第二条现场流程是烫伤,五个字:冲、脱、泡、盖、送。第一步冲最关键,用十五到二十五摄氏度的常温自来水持续冲洗十五到三十分钟,至少十五分钟,时间越长越好。国际上的口径也支持这个量级,英国国家医疗服务体系建议在流动冷水下冲二十分钟,澳新复苏委员会的烧伤急救指南是至少二十分钟,而且强调即使在烧伤后三小时内才开始冷却,仍然可能有帮助。第二步脱,冲洗之后再轻柔地脱去衣物,如果衣物已经和皮肤粘连,用剪刀把周围剪开、保留粘连的部分,避免二次撕裂创面。第三步泡,小面积烫伤可以用冷水浸泡十到二十分钟,但是大面积烫伤以及老人、儿童禁止长时间浸泡。第四步盖,用无菌纱布或者干净棉布轻轻覆盖创面,创面冷却之后可以把保鲜膜平铺覆盖在伤处,注意是平铺,不要缠绕肢体。第五步送,烫伤面积大于手掌、皮肤起泡或者变色、位置在头面部或者关节、患者是婴幼儿或者老人、伤口渗液有异味,以及化学或电烧伤,都要立即就医。四条禁忌请一定记住:不要涂牙膏、酱油、醋、香油、草木灰,也不要涂任何乳膏和油类,它们会封住热量、造成刺激并加重损伤;不要直接用冰块或冰水冷却,可能造成进一步的组织损伤;不要强行撕扯粘在皮肤上的衣物;不要自己挑破水疱,直径小于一厘米的小水疱保留,大于一厘米的必须由医生处理。另外冷却的时候要盖好没有烧伤的部位给伤者保暖,幼儿特别容易迅速出现低体温,还要在肿胀出现之前轻轻摘下戒指、腰带这些紧束的物品。

# 09_master_table

最后一页是可以直接长按保存的总表,把前面八页收进一张表里:分类、物品、要点三列。止血包扎里是无菌纱布各五片、弹力绷带和三角巾、创可贴和医用胶带,要点分别是渗血时加盖不揭、先盖后包力度适中、创可贴黏性会随时间下降。消毒是碘伏加无菌棉签可以直接上伤口、百分之零点九的生理盐水是冲洗伤口的首选、消毒湿巾只擦伤口周围皮肤。常用药按五个用途备,再按家人追加,原则是对症备用不囤货、遵医嘱看说明书。工具是圆头剪刀和镊子用来剪开衣物、取出表浅异物,手套和外科口罩是施救前的防护,电子体温计要选非水银非玻璃的,急救毯和手电筒负责保暖和夜间取用。最后两行是该清出去的:红药水和紫药水含汞或者有致癌风险,过期或变质的药破坏包装之后再丢弃。这张总表是我们的整理,每一条的要点都来自前八页标注的官方来源。最后想留给大家一句话:备对药,再加上懂急救,才是双重保障,建议每个家庭至少有一个人去参加一次红十字会或者急救中心的培训,学会止血、包扎和心肺复苏这些基础技能。
