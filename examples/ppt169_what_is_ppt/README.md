# what_is_ppt

- Canvas format: ppt169
- Created: 20260724
- Runtime: Default (Strategist → Image_Generator → Executor)

## Directories

- `svg_output/`: authored SVG slides (native-export source)
- `svg_final/`: self-contained preview SVGs (images embedded; rendered by the gallery viewer)
- `images/`: AI-generated slide images (compressed for distribution) plus the generation manifest
- `icons/`: project-local icons referenced by the slides
- `notes/`: speaker notes
- `sources/`: source material
- `analysis/`: image facts regenerated by `analyze_images.py`
- `design_spec.md` / `spec_lock.md`: design narrative and execution contract
- `animations.json`: transition and object-animation configuration
- `exports/`: exported PPTX (with speaker notes and animations; no narration audio)

## Regenerate the PPTX

```bash
python3 skills/ppt-master/scripts/svg_quality_checker.py <this_dir> --stage final --json
python3 skills/ppt-master/scripts/svg_to_pptx.py <this_dir> --with-notes
```
