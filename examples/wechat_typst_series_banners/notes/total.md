# 01_series_cover

这是整个“Typst 入门”连载的系列头图，放在第一篇之前，也可以作为合集封面。大字“Typst 入门”后面紧跟一个红色的插入光标，它会在后面每张章节横幅上变成章节轨道下的红色标记。副题“一门简明但强大的现代排版语言”逐字取自《标记模式》开头一句，下面那句“少配置样式，也能获得排版精良的文档”是对同一章第二段设计目标的整理，所以旁边注明了整理出处。底部一行列出本系列的四篇：导引、标记语法、数学公式、中文排版。

---

# 02_ch1_intro

第一篇导引的横幅。左边是章节号和标题，右边先放教程里对 Typst 的定义原句：Typst 首先是一种用于排版文档的标记语言，旨在易于学习、快速且用途广泛。下面的深色排字条是教程给出的两条命令，先用 typst compile 把文件编译成 PDF，再用 typst watch 让编译器进入监视模式，边改边增量编译和预览；这一行说明是整理，不是原句。以后改字复用时，保持章节轨道和红色标记的位置不变。

# 03_ch2_markup

第二篇讲标记语法。副题“语义先行”来自教程里的提示：Typst 总是希望先标记语义，再附加样式。右边左半是四行原样照抄的源码，一个等号开一级标题，两个等号开二级标题；右半是这段源码排出来的样子。底部的引句逐字出自教程：等于号的数量恰好对应了标题的级别。

# 04_ch3_math

第三篇讲数学公式。教程原话是数学模式用一对美元符号进入，所以副题写成“用一对 $ 进入”。排字条里是教程中的行间公式示例，集合 A 由小于十的自然数组成；下方是同一公式在 PowerPoint 里的原生公式排版结果，可以直接编辑。最下面的引句同样逐字取自教程：美元符号内部两侧如果都有空白，就是行间公式。

# 06_follow_cta

放在每篇文末的关注引导。主句请读者关注本号，副句说明这个系列会把 Typst 从标记写到公式，再写到中文。中间的四段路线就是四篇的阅读顺序，红色光标停在末端，表示系列还在继续。下面一行由浅入深的阅读建议整理自导引里推荐的阅读方法：先像写 Markdown 那样写出一篇基本文档，再往后学。最底部注明内容整理自 typst-doc-cn 的中文教程，采用 Apache 2.0 许可。
