# 01_cover

先问在座一个问题:同时按下三个琴键,你听到的是一个和弦,可空气里到底发生了什么?今天这节课只做一件事,把这个问题回答清楚。傅里叶变换说的是,任何随时间变化的东西,都可以换一种写法,写成它由哪些频率组成。这节课四十五分钟,我们会走完级数、变换、快速算法和它们的公式;需要的数学不超过高中的正弦和大学第一学期的积分。还有一件事请放心,幻灯片上每一条公式都是可以直接点开编辑的原生公式,课后想抄走、想改都行,不是图片。

# 02_chord

先把直觉立住。上面那条抖动的线,是麦克风采到的波形,是你真正听到的那一条;下面三条光滑的正弦,是它的三个分量,频率从低到高。三条加起来,就是上面那条,这件事你的耳朵其实一直在做,它能同时听出三个音高,而不是听成一团。每一条分量只需要交代两件事:幅度,也就是它有多响;频率,也就是它有多高。屏幕下方这条式子就是把这句话写成数学。现在把问题倒过来:如果我只给你合成后的那条线,你能不能把每一条的幅度和频率反算出来?接下来的一个小时,都是在回答这个反问。

# 03_series_origin

这套写法不是信号处理发明的,它比信号处理早了一百多年。一八零七年十二月,傅里叶把一份研究热怎么在固体里扩散的手稿交给法兰西研究院,结果因为拉格朗日反对他处理三角级数的方式,没能发表。一八一一年他用修订稿赢得了科学院关于热扩散的悬赏,评审仍然批评他不够严格。直到一八二二年,《热的解析理论》正式出版,这套级数写法才进入数学。请注意他的动机:他要解的是一个物理方程,级数是解方程时逼出来的工具,不是为了压缩音频而设计的。屏幕上这条式子说的是,任何周期函数都能用整数倍频率的正弦和余弦堆出来,常数项加上一串余弦项和正弦项。

---

# 04_coefficients

那么每一条分量占多少,怎么算?答案是做一次积分。看第一条式子,里面有三个部件:积分号加上从零到大写 T 的上下限,意思是在一个周期上取平均;后面那个余弦,是我们事先选定的第 n 条频率,可以把它想成一把尺子;前面的二比 T 是归一化。把待测的信号贴着这把尺子量一遍,别的频率会在积分里相互抵消,只剩下这一条自己的量,这就是正交性。第二条式子和第一条互为镜像,只是把余弦换成正弦,一条量余弦成分,一条量正弦成分。右边那句提醒很重要:周期 T 一旦定下来,可用的频率就只能是基频的整数倍,中间那些频率是取不到的,这个限制会在第三节被打破。

---

# 05_square_wave

来看一个具体的信号,方波。把刚才那两条积分套上去,结果很干净:所有偶次项的系数都是零,只剩奇次谐波,而第 k 项的幅度正比于一比 k。左边这张图就是它的频率清单,第一条是一,第三条掉到零点三三,第五条零点二,第七、第九越来越矮。注意这几个数不是我引用来的,是用下面这条展开式当场算出来的。往回看一眼:一条方波现在变成了一串可以逐项检查的数,你可以照着这份清单再把它合成回去,项数取得越多,拐角越方。顺便说一句,无论取多少项,拐角处永远会留一点过冲,这个现象叫吉布斯现象,今天不展开。

# 06_series_to_integral

到这里我们只会处理周期信号,现在把这个限制拆掉。看这三排刻度,每一根代表一条可用频率。周期是 T 的时候,频率间隔是一比 T;周期拉长到两倍,间隔就缩到一半;拉长到四倍,刻度密到快要连成一片。屏幕中间这条式子是级数系数的复数写法,请盯住它的两个特征:积分区间只覆盖一个周期,前面还挂着一比 T。既然 T 一变大频率就越排越密,那么让 T 一直长到无穷会发生什么?间隔趋于零,离散的频率清单就变成一条连续的谱,求和号也就没法再写成一项一项。下一页,我们把这条式子推过去。

# 07_transform_pair

这就是推过去的结果。同一条式子,积分区间从一个周期张开到整条时间轴,前面的一比 T 消失,离散的下标 n 变成连续的 ω,级数系数 c 下标 n 就变成了连续的 F(ω)。上面这条叫正变换,把随时间变化的 f(t) 读成频率分布;下面这条叫逆变换,把频率分布读回时间。两条合起来是一本可逆的字典,同一份信息,两种写法,来回都不丢东西。最后是一个很实际的提醒:一比二 π 放在哪一侧、指数写成负 i ω t 还是负二 π i f t,各本教材的约定并不相同,本课采用的是美国国家标准与技术研究院数学函数库第一点一四节的写法。换书的时候,先核对约定,再比对结果。

---

# 08_transform_pairs_table

有了变换对以后,大多数题目并不需要重新积分,认样板就够了。第一行,矩形窗变过去是 sinc 函数,窗开得越窄,频谱摊得越宽,这是同一句话的两种说法。第二行,高斯变过去还是高斯,它是唯一形状不变的那一个,变的只是宽度的方向。第三行,一个瞬间的冲击,它的频谱是一条水平的一,意思是一瞬间里含有所有频率;这也解释了为什么敲一下桌子,听起来什么频率都有。第四行反过来,一条纯正弦的频谱只在正负 ω 零两个点上有值。请注意表格里这些式子也都是原生公式,课后可以直接复制去用。遇到新信号,先看它像表里哪一行,再用下一页的性质把它挪过去。

# 09_properties

三条性质,目的都一样,把新信号化归成刚才表里已有的那一行。第一条线性,分开算再相加,这是最常用的一条,复杂信号先拆成简单件。第二条时移,把信号整体往后挪 t 零,频谱的幅度一点没变,只多了一个相位因子;换句话说,声音晚到一点,它含有哪些频率完全不变,变的只是这些频率的起步位置。这也顺带解释了一个常见困惑:为什么幅度谱上看不出延迟。第三条调制,给信号乘上一条载波,等于把整段频谱搬到 ω 零上;调幅广播、上变频,做的就是这件事。会用这三条,很多题目就不必再碰积分。

# 10_convolution

这一页是今天最有工程价值的一条。时域里的卷积,那个需要把一个函数翻过来、逐点滑动相乘再积分的麻烦操作,到了频域只是两条曲线逐点相乘。于是滤波的标准做法变成三步:变到频域,乘一条传递函数,再变回时域。三步里只有中间那一步是设计,两头都是机械操作,而且都由快速算法承担。举个你每天都在用的例子:均衡器上那几个推子,画出来就是传递函数的形状,低频推高一点,齿音压低一点,再变回时域出声。所以调音色和乘一条曲线,是同一件事。前提是两个函数都绝对可积,课堂上遇到的信号一般都满足。

---

# 11_dft

到目前为止公式里都是积分,计算机做不了积分,它只有一串采样点。凭什么可以只取样本?一九四九年香农在《噪声中的通信》里给出了依据:带宽限于 W 的信号,可以由每秒两 W 个采样完全确定,信息一点不少。有了这条,积分就换成有限项求和,连续频率换成 N 个频点,指数里的 ω t 换成二 π k n 比 N,形状一点没变,只是把所有改成有限个。这条式子就是计算机里真正在跑的那一条:N 个复数进去,N 个复数出来,频谱图上的每一根竖线都是它算出来的一个 X 下标 k。剩下的问题只有一个,这条求和,算起来贵不贵。

---

# 12_cost

代价直接写在求和号里。算一个频点,要把全部 N 个样本走一遍;而频点一共有 N 个,于是里外两层都到 N,总代价是 N 的平方。举个数:N 等于一千零二十四的时候,大约要做一百万次复数乘加;把 N 抬到四千零九十六,就跳到千万级。而实时音频每秒钟要做很多次这样的变换,照定义硬算根本撑不住。请注意,慢的不是数学,公式本身没有任何问题,慢的是照定义硬算这件事。一九六五年那篇论文也没有改这条公式,它只是发现:这个求和里有大量重复出现的旋转因子,完全可以只算一次。

---

# 13_cooley_tukey

做法是拆一半。把求和按下标的奇偶分成两组,偶数下标凑出 E 下标 k,奇数下标凑出 O 下标 k,再乘一个旋转因子合起来,就是屏幕上这条式子。关键在于这两半各自又是一个长度为 N 比二的同类问题,于是继续拆下去,一共只有 log 二 N 层,每层的代价是 N,总代价就落到 N 乘 log N。左边这张图用线性刻度画了两条曲线:红色那条是照定义硬算,到 N 等于一千零二十四时已经冲到一百万以上;青色那条就是快速算法,只有一万出头,几乎贴在横轴上。这两个数是按两条量级公式直接算出来的。出处是库利和图基一九六五年发表在《计算数学》上的论文;更早的史前史也值得一提,高斯大约在一八零五年的未发表手稿里已经用过等价的做法,这一考证见一九八四年海德曼等人的文章。

# 14_applications

频域不是黑板上的技巧,它已经写进标准里。第一个,图像:基线 JPEG 把图像切成八乘八的小块,每一块做一次离散余弦变换,再量化、编码,这是一九九二年 ITU-T T.81 规定的。第二个,医学:核磁共振成像的采集,本质上是在傅里叶空间,也就是 k 空间,沿着一条轨迹采样,再变换回图像,这个表述来自一九八三年特维格的论文。第三个,无线:Wi-Fi 的二十兆赫兹 OFDM 用的是六十四点快速傅里叶变换,其中四十八个数据子载波加四个导频;子载波间隔三百一十二点五千赫兹,是二十兆赫兹除以六十四算出来的。第四个,声音,就是刚才那个均衡器。最下面这条式子是 JPEG 里那次离散余弦变换的完整写法,你会发现它和我们一路推下来的形状是同一套思路,只是换了一组基函数。

# 15_closing

带走三句话。第一句,时域和频域是同一份信息的两种写法,靠一对积分互相翻译,不存在哪一边更真实。第二句,滤波、均衡、模糊,在频域都只是一次乘法,这就是卷积定理,它是频域最值钱的一条。第三句,快速傅里叶变换没有换数学,它只换了算路,把代价从 N 的平方降到 N 乘 log N。接下来两条路,任选一条:想把理论走扎实,斯坦福的 EE261 公开课系统讲变换对和性质;想把手感练出来,就自己写一个八点的离散傅里叶变换,再和现成库函数的结果逐项对一遍,这一步比看十页推导有用。最后一句话送给今天的内容:记号是门槛,思想不是,它只是把怎么变,翻译成由哪些频率组成。本课全部事实的出处都在工程的事实清单里,课后可以自己核。
