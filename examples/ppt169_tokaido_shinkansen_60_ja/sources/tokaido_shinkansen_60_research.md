# 東海道新幹線 60年 — 調査補足

## Research Brief

- **ベースライン**:ユーザー提供資料なし(題目のみ)。「東海道新幹線の開業60年を振り返るプレゼンを日本語で、一般向けの講演用、15枚前後」。
- **調査ギャップ**:(1) 開業の背景と開業時の姿、(2) 速度と車両の変遷(0系〜N700S)、(3) 運行本数・輸送量・定時性の数字、(4) 安全記録と地震防災、(5) 次の60年(中央新幹線の公表済み計画と現状)。
- **聴衆・意図**:一般聴衆向けの講演。確認はユーザーから委任済み。
- **求める成果**:出典名と参照年を添えた、検証可能な数字だけで組み立てる日本語デッキ。
- **採用しなかった数字**:建設費・世界銀行融資額など、一次資料で追跡できなかった「よく流布する数字」は採らない。60周年当日の「延べ70億人」は報道のみで確認し、JR東海一次資料の数字(F002・F003)を優先する。

## 1. 開業の背景と開業時の姿

- 1964年10月1日開業(F001)。
- 在来線で約6時間かかっていた東京〜(新)大阪を、開業時は4時間で結び、翌年には210km/h運転で3時間10分を実現(F011)。
- 開業時の運転本数は1日平均60本(F004)。

## 2. 速度と車両の変遷

- 最速列車の東京〜新大阪所要時間:1964年度 4:00 → 1965年度 3:10 → 1984年度 3:08 → 1986年度 2:52 → 1987年度 2:49 → 1991年度 2:30 → 2007年度 2:25 → 2014年度 2:22 → 2020年度 2:21(F010)。2026年3月ダイヤ改正時点でも2時間21分(F009)。
- 型式別の東海道区間最高速度:0系 210km/h(1986年11月に220km/h化)、100系 220、300系 270、700系 270、N700系 270(改造後285)、N700A 285、N700S 285(F012)。
- 営業開始:100系 1985年10月(F013)、300系 1992年3月(F014)、700系 1999年3月(F015)、N700系 2007年7月(F016)、N700A 2013年2月(F017)、N700S 2020年7月(F018)。
- 技術の要点:300系はアルミ合金車体・誘導電動機で0系比約30%軽量化し、東京〜新大阪2時間30分(F014)。N700系は新幹線初の車体傾斜システム(F016)。2015年3月に最高速度285km/h運転開始(F017)。N700SはSiC素子の駆動システムを高速鉄道で世界初採用(F018)。
- 2003年10月、品川駅開業とともに全列車270km/h化(F019)。
- 型式ごとの技術の追補:0系はオール電動車で1986年11月に220km/h化(F037)、700系は「エアロストリーム形」の先頭形状で空力を改善(F038)、N700Aは中央締結ブレーキディスクと地震ブレーキ(F039)。

## 3. 運行本数・輸送量・定時性

- 列車本数:開業時 1日平均60本 → 2024年度 383本(F004)、2025年度 395本/日(臨時列車含む)(F005)。
- 「のぞみ」の1時間あたり片道最大本数:1992年度 1本 → 2003年度 7本 → 2019年度 12本(F021)、2026年3月から13本(F021)。
- 輸送人員:2025年度 50.4万人/日、1億8,400万人/年(F006)。
- 累計利用者:開業以来約68億人(2024年2月発表)(F002)、約72億人(JR東海採用サイト、2026年時点の記述)(F003)。
- 輸送人キロ(億人キロ):1987年度 321 → 2019年度 540 → 2020年度 182(コロナ禍) → 2025年度 609(F020)。年度別系列はF020に記録。
- 平均遅延:1.0分/運行1列車(2025年度、自然災害等による遅延を含む)(F007)。
- 輸送力:東京圏〜大阪圏で1日約38万席(航空は約3万席、2025年4月)(F022)。対航空シェア 鉄道86%・航空14%(東京圏〜大阪圏、2024年度)(F023)。
- 環境:東京〜大阪の1座席当たりエネルギー消費は航空機の約8分の1、CO₂は約12分の1(F024)。

## 4. 安全記録と地震防災

- 開業以来、乗車中のお客様が死傷される列車事故ゼロ(F008)。
- 地震防災システム:遠方地震計(21箇所)・沿線地震計(50箇所)・緊急地震速報(地震計約1,000)でP波を捉え、送電停止で列車を自動停止(F025)。通称「テラス」、2008年から緊急地震速報と併用(F027)。
- 早期化:推定に必要なデータを2秒→1秒に短縮、海底地震観測網の活用で南海トラフ最大約15秒・日本海溝最大約30秒の早期検知(F026)。
- 脱線・逸脱防止:脱線防止ガード約937km完了(2025年度末)、2028年度までに全線完了見込み。逸脱防止ストッパは全車両に設置済み(F028)。
- 構造物の耐震補強:高架橋柱 約19,600本・橋脚 約900基・盛土 約9.4kmで完了(2025年度末)(F029)。
- 大規模改修工事:2013年度に着手(F035)。

## 5. 次の60年(中央新幹線)

- 超電導リニアで営業速度500km/h。技術は国交省の評価委員会で「営業線に必要な技術開発は完了」と評価(F030, F034)。
- 所要時間:品川〜名古屋 最速86分→40分、品川〜大阪 最速134分→67分(F030)。
- 品川〜名古屋間:2023年12月の認可で工事完了予定は「2027年以降」。南アルプストンネル静岡工区の掘削着手の見込みが立たず、新たな開業時期は見通せない(F031)。
- 総工事費:7.04兆円から11.0兆円となる見通し(2025年10月発表)(F032)。
- 工事状況(2026年3月末):工事契約82件(約286kmの約9割)、用地取得約85%(F033)。
- 東海道新幹線の経年劣化と大規模災害への備えとして、大動脈の二重系化を目指す(F036)。

## 資料間の相違

- 700系の最高速度:日本機械学会誌の記事本文は「最高速度285km/h」と書くが、同記事の図とファクトシートは東海道区間270km/h(285km/hは山陽区間)。本調査は東海道区間の値(F012)を採る。
- N700Aの投入年:同記事内で「2012年から」「2013年から」が混在。JR東海採用サイトの「2013年2月」(F017)を採る。
