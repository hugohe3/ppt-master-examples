## III. Visual Theme

### Theme Style

- **Mode**: custom
- **Mode References**: briefing
- **Mode Behavior**: 以 briefing 为唯一基底：逐页中立、完整、可查找；源稿 20 页一一对应、顺序与文字逐字不变，页标题沿用源稿的章节式主题标题（"一、出台背景""四、规范内容"），同级条款同形同权，只在源稿已标注的关键词、时限与禁止事项上加强强调，不制造结论句。
- **Visual style**: custom
- **Visual Style Behavior**: 政务条文手册：白色纸面，页眉用左侧深色主题标题 + 蓝色章节标签 + 右上角圆形厅徽，页眉下一条细分隔线，其左段由一段蓝色山形折线（取自厅徽的山形）替代直线，作为全篇母题；条款抬头用满宽蓝色条带（白字、黄色高亮关键词），并列条款用同尺寸浅蓝底面板或编号行，编号用大号蓝色数字或圆形编号牌，流程用竖向或横向编号轨道并以连接线表达先后；小圆角（6px）、无投影或仅截图卡片有轻微投影；强调只用两级色：蓝色加粗标关键词，红色加粗标时限、禁止与关键结论；截图以白边卡片呈现，剪贴画保留原貌并加细框。
- **Theme**: 吉林省自然资源厅政务蓝身份延续——源稿蓝色页眉、红色强调、厅徽；把源稿零散的色块与艺术字统一为一套条文手册版式
- **Tone**: 庄重、清楚、便于查找

## V. Layout Principles

### Deck-wide Direction

- **Hierarchy direction**: 页眉主题标题 → 条款条带/小标题 → 编号条目或段落；读者先定位"在讲哪一章哪一条"，再逐条读
- **Composition tendency**: 条款页用"蓝色条款条带 + 编号网格/编号轨道"；流程与时限页用带连接线的编号轨道；带图页用图文分栏，截图以卡片呈现；封面与封底用满宽蓝色带承载标题
- **Cross-page continuity**: 页眉（主题标题 + 章节标签 + 厅徽 + 山形折线分隔线）在第3–19页恒定；第8、9、11、13页的"第X条：X单位在项目实施过程中职责"条带同形；编号牌样式全篇一致
- **Spacing posture**: 以 dense 为主，按 page_rhythm 在第12、18页放开留白
- **Spacing anchors**: page margin 56px · block gap 24px · column gutter 32px · corner radius 6px · body leading 1.45×（24px 正文行距约 35px）

  - 01 初选申报：由市、县级自然资源主管部门主要根据本级地质灾害防治规划及突发灾情险情，在重点区域内确定初选项目，组织编制项目可行性研究报告，会同同级财政部门制定资金筹措方案经同级人民政府批准后，填报项目绩效目标表，报上一级自然资源主管部门核查。 ※对于跨行政区的地质灾害治理工程项目，由共同的上一级自然资源主管部门，明确其中一个市、县级自然资源主管部门组织申报。
  - 02 现场核查。对市、县级自然资源主管部门确定的初选项目，上一级自然资源主管部门要组织专家现场核查，形成核查意见后，由市（州）级自然资源主管部门向省自然资源厅和省财政厅统一申报。对拟申请中央财政资金支持的，按照《中央财政自然资源领域转移支付资金项目储备库入库指南》相关要求申报。

  - 强调：红——初选申报、重点区域、※、跨行政区、现场核查。、上一级、评估审核。、动态调整。；蓝——初选项目、可行性研究报告、同级财政部门制定资金筹措方案、填报项目绩效目标表、主管部门核查、形成核查意见、《中央财政自然资源领域转移支付资金项目储备库入库指南》、每年至少组织专家评审一次、不能立项的、项目调整出库

- **Content**:
  - 第五章 工程运行管护（第二十二条）
  - 施工单位在向建设单位提交工程竣工验收报告时，应当出具工程质量保修书。质量保修书中应当明确地质灾害治理工程的保修范围、保修期限和保修责任等，保修期限以施工合同约定为准，自竣工验收通过之日起计算。国家对保修期限有明确规定的，施工合同约定的保修期限不得低于国家规定。（蓝：工程质量保修书；红：保修范围、保修期限、保修责任）
  - 明确管护责任：市、县级自然资源主管部门应在项目竣工验收合格并投入运行的15个工作日内，与指定的管护单位进行交接，签订《工程移交接管协议书》，明确管护单位管理维护制度，做好项目后续管理和维护。（红：15个工作日内；蓝：工程移交接管协议书）
  - 加强后续管护：市、县级自然资源主管部门应在项目治理区内设置标牌，载明项目勘查、设计、施工、监理、管护等单位相关信息，加强项目运行管护监督，督促管护单位履行好工程运行管护责任。在保修期限内发生质量问题的项目，由项目施工单位进行维修，所需维修费用由相关责任方按照国家和省有关规定承担；超出保修期限后，项目管护费用由管护单位承担。（蓝：设置标牌、单位相关信息、超出保修期限、管护单位；橙：保修期限内、施工单位）
  - 履行认定核销程序：经工程治理后的隐患点，由市、县级自然资源主管部门根据专家组竣工验收意见，向省自然资源厅申请地质灾害隐患点核销或降级。（蓝：工程治理后的隐患点；红：核销或降级）
